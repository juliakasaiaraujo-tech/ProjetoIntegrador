Módulo 04 · Programação

O cérebro por trás do aquecimento

A lógica de controle automatizado, o código do Arduino e um simulador para você testar o sistema agora mesmo.

Lógica de controle

O passo a passo do programa

  1. 1

    Leitura

    O sensor mede a temperatura da água a cada ciclo do programa.

  2. 2

    Comparação

    O Arduino compara o valor lido com a temperatura ideal (30 °C no simulador).

  3. 3

    Aquecimento

    Se a água estiver fria demais, o relé é acionado e o aquecedor liga.

  4. 4

    Desligamento

    Ao atingir o alvo, o relé desliga — evitando desperdício de energia (histerese).

  5. 5

    Exibição

    O display OLED atualiza temperatura e status em tempo real.

  6. 6

    Acessibilidade

    Sensores de presença detectam usuários e ativam a rampa motorizada quando necessário.

Código Arduino

O programa, explicado

O sketch roda em dois blocos clássicos do Arduino: o setup(), que prepara pinos, sensor e display uma única vez; e o loop(), que repete para sempre o ciclo ler → comparar → agir → exibir.

A banda de histerese (±0,5 °C) impede que o relé fique ligando e desligando sem parar quando a temperatura está bem perto do alvo — protegendo o equipamento e economizando energia.

O display OLED mostra a temperatura com números grandes e alto contraste: informação perceptível para qualquer usuário, reforçando a acessibilidade.

💾 aquamais.ino — versão resumida
#include <OneWire.h>
#include <DallasTemperature.h>
#include <Adafruit_SSD1306.h>

#define PIN_SENSOR 2
#define PIN_RELE   8

const float ALVO  = 30.0;  // temperatura ideal (°C)
const float BANDA = 0.5;   // histerese (±°C)

OneWire oneWire(PIN_SENSOR);
DallasTemperature sensor(&oneWire);
Adafruit_SSD1306 display(128, 32);

void setup() {
  pinMode(PIN_RELE, OUTPUT);
  digitalWrite(PIN_RELE, LOW);  // começa desligado
  sensor.begin();
  display.begin(SSD1306_SWITCHCAPVCC, 0x3C);
}

void loop() {
  sensor.requestTemperatures();
  float t = sensor.getTempCByIndex(0);

  if (t < ALVO - BANDA)          // água fria?
    digitalWrite(PIN_RELE, HIGH); // liga aquecedor
  else if (t >= ALVO)            // chegou no alvo?
    digitalWrite(PIN_RELE, LOW);  // desliga

  display.clearDisplay();
  display.setTextSize(2);
  display.print(t);
  display.print(" C");
  display.display();
  delay(1000);
}

Interatividade + acessibilidade

Simulador de LED RGB: a temperatura em cores

No projeto, o LED RGB funciona como alerta visual — essencial para quem não percebe alertas sonoros. Aqueça ou esfrie a piscina e veja a cor mudar em degradê, junto com os valores que o Arduino enviaria aos pinos do LED (PWM, 0–255).

💡 Azul = fria · Verde = pronta · Vermelho = quente demais. Assim, qualquer pessoa entende o estado da piscina só de olhar — mesmo sem ouvir nada.
